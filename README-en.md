Welcome to Klevor's repository, the robot of Team Steel Bot, competing in the World Robot Olympiad 2025 in the Future Engineers category. Here you will find all the information about the robot, including its code, 3D models, schematics, and documentation.

## How can I access this documentation?

Currently, all of the official documentation can be found in [GitHub Pages](https://klevor.ralvarez.dev), as well as its [GitHub repository](https://github.com/teamsteelbot/klevor), we recommend to view this documentation in GitHub Pages, as it was made to fit better this format. This documentation is organized in multiple sections, each of them containing specific information about the robot and its development.

## Documentation Structure

This documentation is quite extensive, so we decided to split the contents into multiple files for readability. These files are located inside the `docs` folder; it is worth mentioning that, a file ending in `.es.md` is written in Spanish, and a file ending in `.en.md` is written in English.

The documentation structure is as follows:

- Inside the `assets` folder you can find the images and videos used for this `README`.

- Inside the `devices` folder you can find the source code used for Klevor, separated in two folders, one for the Raspberry Pi 5's code, and the other for the Raspberry Pi Pico 2 W's code.

- Inside the `docs` folder, as we mentioned previously, you can find all of Klevor's documentation, which is divided in 3 sections, the electronic, mechanical and programming, aside from these sections, we have miscellaneous files that detail, for example, the software we used, the "gadgets" or tools we used, how you can contact the team, and more, **these files are listed at the index's bottom**.

- Inside the `models` folder you can find all of the 3d printed pieces' models used in Klevor, this folder is divided between the part drawings, the `.stl` file to print them, and, organized between prototipes as well.

- Inside the `schemes` folder you can find the flowcharts and wiring diagrams, on top of this, we included some diagrams that explain how each of the system's components communicate and how are they processed inside the Raspberry Pi.

- Inside the `t-photos` folder you can find the team's photos.

- Inside the `v-photos` you can find Klevor's photos,

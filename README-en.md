Welcome to the Klevor repository, the robot of Team Steel Bot, competing in the World Robot Olympiad 2025 in the Future Engineers category. Here you will find all the information about the robot, including its code, 3D models, schematics, and documentation.

Currently, all the official documentation is available [here](https://klevor.ralvarez.dev), on GitHub Pages, where you can access all the documentation present in this repository in an easy and fast web format. This documentation is organized into several sections, each containing specific information about the robot and its development.

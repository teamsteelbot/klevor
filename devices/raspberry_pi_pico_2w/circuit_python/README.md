# Código

> [!IMPORTANT]
> El desarrollo actual de Klevor está basado en TinyGo.

Esta carpeta tiene todo el código realizado en CircuitPython para el desarrollo de Klevor, se recomienda utilizar una Raspberry Pi Pico 2 WH (aunque, cualquier microcontrolador con CircuitPython debería de poder funcionar si se hacen algunas correcciones) para poder ejecutar los archivos.

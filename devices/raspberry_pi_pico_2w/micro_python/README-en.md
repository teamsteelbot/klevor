# Code

> [!IMPORTANT]
> The current development of Klevor for the Raspberry Pi Pico 2 WH is based on [TinyGo](../tinygo/README-en.md).

This folder contains all the code developed in MicroPython for the development of Klevor. It is recommended to use a Raspberry Pi Pico 2 WH (although any microcontroller with MicroPython should work with some adjustments) to run the files.

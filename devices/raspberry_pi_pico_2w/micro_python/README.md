# Código

> [!IMPORTANT]
> El desarrollo actual de Klevor para la Raspberry Pi Pico 2 WH está basado en [TinyGo](../tinygo/README.md).

Esta carpeta contiene todo el código desarrollado en MicroPython para el desarollo de Klevor, se recomienda utilizar una Raspberry Pi Pico 2 WH (aunque, cualquier microcontrolador con MicroPython debería de poder funcionar si se realizan ciertos ajustes) para poder ejecutar los archivos.

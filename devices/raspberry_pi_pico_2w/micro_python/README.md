# Código

> [!IMPORTANT]
> El desarrollo actual de Klevor está basado en TinyGo.

Esta carpeta contiene todo el código desarrollado en MicroPython para el desarollo de Klevor,  se recomienda utilizar una Raspberry Pi Pico 2 WH (aunque, cualquier microcontrolador con MicroPython debería de poder funcionar si se hacen algunas correcciones) para poder ejecutar los archivos.

Se realizaron cambios drásticos en este nivel, enfocándonos principalmente en modificar el grosor de la capa para aligerar el peso. Además, se añadieron nuevos huecos estratégicamente ubicados para facilitar el montaje y la integración de los componentes. Toda la base fue fabricada completamente a medida, diseñada específicamente para adaptarse a las dimensiones y requerimientos de los elementos que estamos utilizando en el robot.

Esta pieza también ha experimentado muchísimos cambios en comparación con el prototipo 2. Principalmente, tuvimos que reducir sus dimensiones y peso para asegurarnos de que no superen el límite máximo permitido. Sobre esta capa se encuentran ubicados dispositivos clave como la [Shargeek Storm 2](../../electronic/components/current.es.md#shargeek-storm-2) y la [Raspberry Pi 5](../../electronic/components/current.es.md#raspberry-pi-5-16gb-ram) por lo que su diseño se adaptó para brindar soporte seguro y una buena integración de estos importantes componentes.
